# Data Dictionary — infinity-grove

> Generated by the Reversa Archaeologist, 2026-11-12. Source: Flyway `backend/src/main/resources/db/migration/V1..V7` and the JPA entities in `adapter/repository/`. 🟢 unless marked.
> Database: PostgreSQL 16 (tests run 17). Hibernate `ddl-auto: validate`: Flyway owns the schema. Every time is epoch milliseconds (`bigint`).
> FK policy (V1 header): rows owned by a player `ON DELETE CASCADE` with `users`; references to a catalog `ON DELETE RESTRICT`.

## Player tables (cascade with `users`)

### `users`
| Column | Type | Null | Notes |
|--------|------|------|-------|
| username | varchar(255) | PK | trimmed, non-blank |
| password | varchar(255) | no | BCrypt hash; raw password ≥ 8 chars |
| created_at | bigint | no | |
| last_login_at | bigint | no | updated on login |

### `refresh_tokens`
| Column | Type | Null | Notes |
|--------|------|------|-------|
| token_hash | varchar(255) | PK | SHA-256 hex of a 32-byte base64url secret; the raw value is never stored |
| username | varchar(255) | no | FK cascade; index `idx_refresh_tokens_username` |
| expires_at | bigint | no | issue + 30 days |
| revoked | boolean | no | set on refresh (rotation), logout, password change |

### `progress` (lock #1 of the lock order)
| Column | Type | Null | Notes |
|--------|------|------|-------|
| username | varchar(255) | PK | FK cascade |
| chapter, stage | integer | no | composite FK `(chapter, stage)` → `stages (chapter, number)` RESTRICT |
| encounter | varchar(32) | no | PHASE, MINIBOSS, CHAPTER_BOSS |
| phase | integer | no | 1 outside PHASE |
| completed | boolean | no | true after chapter 5's boss |

### `player_cards` (lock #2, "the player lock")

### `player_talents` (V3)
| Column | Type | Null | Notes |

### `talent_point_awards` (V5)
| Column | Type | Null | Notes |
|--------|------|------|-------|
| username | varchar(255) | PK part | FK cascade |
| award_key | varchar(64) | PK part | `chapter:stage:encounter:phase`, or `legacy` |
| points | integer | no | CHECK ≥ 0 |

V5 granted each existing owner a `legacy` award equal to `sum(level)` (the levels they bought with coins before points existed). 🟡 An account reset deletes all awards, `legacy` included.

## Main API DTOs

| DTO | Fields |
|-----|--------|
| `AuthResponse` | `user{username, createdAt, lastLoginAt}`, `accessToken`, `refreshToken`, `accessTokenExpiresAt`, `refreshTokenExpiresAt` |
| `ProgressResponse` | `chapter, stage, encounter, phase, completed, definition{bossHealth, bossTimeLimitMs, boss, bossDropRuleId, stages[]}`, plus `drop`, `equipmentDrop`, `talentPoints` on an outcome |
| `HeroResponse` | `id, name, heroClass, element, leaderBonus, portrait, chapter, owned, stars, copies{"0".."9"}, skills[{slot, name, type, effect, cooldownSeconds, image, unlocked, level}]` |
| `WalletResponse` / `SyncResponse` | `wallet{gold, silver, copper}`, `drops{"<ruleId>": int[20]}`, plus `accepted{"<ruleId>": n}` on a sync |
| Equipment piece | `id, slot, rarity, refine, clickDamage?, affixes[{type, value}], heroId?, refineCost?, rerollCost?, sellPrice` (values already refined) |
| Talents | `talents[{id, baseId, branch, label, unit, perLevel, maxLevel, level, value, nextCost, ...}]`, `points{earned, spent, available}` |
| `AutoClickResponse` | `level, maxLevel, intervalMs, crystals, next{level, intervalMs, price}?, resets` |
| `ResetResponse` | `reward, crystals, resets, progress` |
| Error (ProblemDetail) | `type, title, status, detail, code` (+ `progress` or `autoClick` on some 409s) |
