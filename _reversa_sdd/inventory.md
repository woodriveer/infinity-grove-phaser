## Overview

Infinity Grove is a browser idle/clicker RPG: a Phaser 3 game (`game/`) backed by a Kotlin Spring Boot REST API (`backend/`) on PostgreSQL, with a self-hosted blue-green deploy pipeline (`deploy/`, `publish.sh`, `deploy.sh`) that ships the game as a Cloudflare Worker through a `cloudflared` quick tunnel.

## Configuration

- `backend/src/main/resources/application.yaml`: datasource, `ddl-auto: validate`, `app.security.jwt-secret: ${JWT_SECRET}` (required, at least 32 bytes), game tuning under `app.cards`, `app.equipment`, `app.auto-click`.
- `game/.env.development|staging|production|pages`: `VITE_API_BASE_URL`, `VITE_API_TIMEOUT_MS`, `API_PROXY_TARGET`.
- `game/vite.config.js` (dev proxy, istanbul instrumentation when `VITE_COVERAGE=true`), `game/wrangler.jsonc` (Worker, SPA fallback, `/api/*` runs the worker first).
- `.env` at the root (not read by the Scout), `.deploy-state` (watcher state).

## CI/CD

- 🟢 No hosted CI (no `.github/workflows`, Jenkinsfile or GitLab CI).
- 🟢 Local continuous deploy: `publish.sh` starts the Docker blue-green stack (Postgres 16, `backend-blue`/`backend-green`, Traefik v3.7.15 on `127.0.0.1:8080`, Dozzle v11.3.5 on `:8888`), a `cloudflared` quick tunnel and `deploy/watcher.mjs`, which polls `origin/main` every 60 s. Backend commits build into the idle slot, pass `deploy/regression.mjs` and switch with no downtime; game commits republish the Worker.
- `backend/Dockerfile`: multi-stage `eclipse-temurin:25.0.4.1_1` (jdk build, jre runtime), built from `git archive <hash>:backend`.
